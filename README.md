# Laboratório de Algoritmos Clássicos

App Flask com 6 algoritmos (Fibonacci, Fatorial, MDC, Crivo de Eratóstenes, Busca binária, Bubble sort).

Rodar localmente:
    pip install -r requirements.txt
    python app.py   # http://localhost:5000

Deploy no Render: Build `pip install -r requirements.txt` | Start `gunicorn app:app`
